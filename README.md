# BABA HIBIKI | ARCHIVE

馬場響生のイラストレーション・アーカイブ。

## GitHub Pages の公開設定
1. Repository の **Settings** を開く
2. 左メニューの **Pages** を選択
3. Source を **Deploy from a branch** に設定
4. Branch を **main**、Folder を **/ (root)** にして Save
5. 数分後、Pages に表示される URL から閲覧できます

## 更新
- `index.html` を編集して作品名、制作記録、提供先を更新します。
- 作品画像は `images/` フォルダに追加し、HTMLの仮枠と差し替えてください。
- 公開する作品・提供先の名称は、公開許可を得たものだけ掲載してください。
